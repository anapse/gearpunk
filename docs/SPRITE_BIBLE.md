# GEAR RUSH — SPRITE BIBLE

## Reglas
Crear todo el arte como una familia visual única.
Pixel art 2D de alta claridad.
Fondo transparente para sprites de gameplay.
No incluir textos dentro de sprites de gameplay.
No cambiar el diseño del personaje entre poses.

## Player
Pose sheets:
- idle
- crouch/pre-jump
- jump up
- jump up-left
- jump up-right
- airborne
- falling
- grab with both hands
- hanging
- climbing
- landing
- hurt
- dead/falling
- victory

La orientación izquierda/derecha se puede conseguir por flip horizontal siempre que no se rompan detalles direccionales.

## Gears
Base sprite reutilizable.
Variantes visuales:
- clockwise
- counterclockwise
- large
- small
- fast
- static
- electric
- explosive
La flecha debe comunicar el sentido de giro de forma inmediata.

## Collectibles
- lightning
- star
- diamond
- heart
- magnet
- clock

## Effects
- sparks
- smoke
- explosion frames
- collection flash
- jump trail
- landing impact
- lava animation

## Fondos
- factory lower
- machinery
- electric zone
- upper factory
- extreme/lava zone

## Prohibido
No generar UI dentro de los sprites.
No poner nombres debajo de personajes.
No incluir botones.
No mezclar personajes secundarios que no estén definidos.
