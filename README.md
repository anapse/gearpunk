# GEAR RUSH

Vertical pixel-art platformer for mobile and PC.

The player is a punk rocker climbing a factory of rotating gears while escaping rising lava.

## Controls
Swipe or drag with mouse:
- up-left
- up
- up-right

## Stack
React + Vite + Canvas.
