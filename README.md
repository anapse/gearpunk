# ⚙️ GEAR RUSH

**Gear Rush** es un emocionante juego de plataformas arcade de estilo steampunk donde la precisión y la rapidez son la clave. Escala a través de una fábrica infinita llena de engranajes giratorios, evita trampas mortales y escapa de la lava ardiente que asciende sin descanso.

## 🚀 Características Principales

*   **12 Zonas Únicas:** Desde la "Fábrica Inferior" hasta el "Olvido Final", pasando por cumbres nevadas y el núcleo estelar.
*   **Mecánicas Dinámicas:** 
    *   **Engranajes Explosivos:** ¡Salta antes de que detone la bomba de 5 segundos!
    *   **Zonas de Clima:** Lluvia intensa que afecta la visibilidad y hace las superficies resbaladizas.
    *   **Engranajes Congelados:** Más rápidos y traicioneros.
    *   **Peligros Eléctricos:** Esquiva las chispas de alto voltaje.
*   **Power-ups Legendarios:** Colecciona Rayos, Diamantes, Estrellas y el rarísimo **Rubí Legendario** para maximizar tu puntuación.
*   **Controles Intuitivos:** Diseñado para gestos táctiles (swipe) y teclado.

## 🕹️ Cómo Jugar

1.  **Saltar:** Desliza (swipe) hacia arriba, izquierda o derecha para saltar en esa dirección.
2.  **Agarrar:** Tu personaje se agarrará automáticamente al borde de los engranajes si saltas hacia ellos.
3.  **Escalar:** Mantente en movimiento para evitar que la lava te alcance o para que las superficies resbaladizas no te hagan caer.
4.  **Meta:** ¡Alcanza los 9000 metros para completar el desafío maestro!

## 🛠️ Tecnologías Utilizadas

*   **React + TypeScript**
*   **Vite** (Motor de desarrollo rápido)
*   **Tailwind CSS** (Estilización moderna)
*   **Canvas API** (Renderizado de píxeles de alto rendimiento)
*   **Lucide React** (Iconografía)

## 📦 Instalación y Desarrollo

Si deseas ejecutar el proyecto localmente:

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Construir para producción
npm run build
```
